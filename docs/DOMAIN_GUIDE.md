# 🌐 Guide : Domaine Personnalisé GRATUIT

## Option 1 : Sous-domaine Netlify (Déjà actif ✅)

Vous avez déjà : `https://random-name-123456.netlify.app`

**Pour le personnaliser :**
1. Allez dans Netlify → **Site settings** → **Domain management**
2. Cliquez sur **Options** → **Edit site name**
3. Choisissez : `tsitana-khyme.netlify.app` ou `khyme-portfolio.netlify.app`
4. ✅ Gratuit et instantané

## Option 3 : Sous-domaine gratuit avec services tiers

### A. **is-a.dev** (Recommandé pour développeurs)
- Domaine : `tsitana-khyme.is-a.dev`
- **100% gratuit**, pas d'expiration
- Prestigieux pour développeurs

**Comment obtenir :**
1. Fork le repo : https://github.com/is-a-dev/register
2. Ajoutez un fichier `domains/tsitana-khyme.json` :
```json
{
  "owner": {
    "username": "Khyme667",
    "email": "tsitanakhyme@gmail.com"
  },
  "record": {
    "CNAME": "votre-site.netlify.app"
  }
}
```
3. Pull Request
4. Approuvé en 1-2 jours

### B. **eu.org**

- Plus long à obtenir (2-3 semaines validation manuelle)

### C. **pp.ua**

## 📋 Configuration dans Netlify (une fois domaine obtenu)

1. **Site settings** → **Domain management**
2. **Add custom domain**
3. Entrez votre domaine : `tsitana-khyme.is-a.dev`
4. Netlify vous donne un DNS à configurer
5. Ajoutez-le chez votre fournisseur de domaine
6. SSL automatique en 24h ✅
