# 📊 Google Analytics 4 - Guide de configuration

## Étape 1 : Créer un compte Google Analytics

1. Allez sur : https://analytics.google.com/
2. Connectez-vous avec votre compte Google
3. Cliquez sur **Commencer** ou **Admin** (roue dentée en bas à gauche)
4. Créez un **Compte** :
   - Nom du compte : `Portfolio Tsitana Khyme`
   - Cochez les options de partage (optionnel)
5. Créez une **Propriété** :
   - Nom de la propriété : `Portfolio Website`
   - Fuseau horaire : `(GMT+03:00) Madagascar`
   - Devise : `Euro (EUR)`
6. Renseignez les infos sur l'entreprise :
   - Secteur : `Technologie`
   - Taille : `Petite entreprise (1-10)`
   - Objectifs : `Obtenir des insights sur mes clients`
7. Acceptez les conditions

## Étape 2 : Configurer le flux de données Web

1. Choisissez la plateforme : **Web**
2. Configurez le flux :
   - **URL du site Web** : `https://votre-site.netlify.app`
   - **Nom du flux** : `Portfolio Website`
   - Cliquez sur **Créer un flux**

## ⚡ Alternatives gratuites

Si vous préférez quelque chose de plus simple :
- **Plausible Analytics** (payant mais simple)
- **Umami** (open-source, gratuit, auto-hébergé)
- **Simple Analytics** (payant mais privacy-first)
- **Netlify Analytics** (19$/mois - pas gratuit)

**Google Analytics 4 reste le meilleur choix gratuit** avec le plus de fonctionnalités.
