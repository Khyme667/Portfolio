1. Allez sur : https://search.google.com/search-console
2. Ajoutez votre propriété : `https://votre-site.netlify.app`
3. Vérifiez avec fichier HTML ou meta tag
4. Soumettez le sitemap : `https://votre-site.netlify.app/sitemap.xml`

**Avantages :**

- Détecter les erreurs SEO
- Voir les requêtes qui amènent des visiteurs
